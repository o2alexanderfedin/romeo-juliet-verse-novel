## Part 1: Forbidden Rhymes Reference (Memorized)

### ❌ NEVER Rhyme These:

#### 1. Verb Infinitives (-ть, -ти endings)
```
❌ любить / говорить     (to love / to speak)
❌ идти / найти           (to go / to find)
❌ петь / гореть          (to sing / to burn)
```
**Why forbidden**: Too easy, banal, shows lack of craft

#### 2. Verb Conjugations (Same tense/person)
```
❌ говорит / звонит       (he speaks / he calls)
❌ любит / губит          (loves / ruins)
❌ пишет / дышит          (writes / breathes)
```
**Why forbidden**: Grammatical rhymes, mechanical, lazy

#### 3. Verb Past Tense (Same ending)
```
❌ сказал / показал       (said / showed)
❌ ушёл / нашёл           (left / found)
❌ любил / губил          (loved / ruined)
```
**Why forbidden**: Same ending across all masculine past verbs

#### 4. Grammatical Case Endings (Same case)
```
❌ дома / города          (genitive singular)
❌ душой / судьбой        (instrumental)
❌ ночами / очами         (instrumental plural)
```
**Why forbidden**: Pure grammar, not poetic craft

#### 5. Trite/Overused Pairs
```
❌ любовь / кровь         (love / blood) - Most cliché pair in Russian
❌ розы / морозы          (roses / frosts) - Overused
❌ слёзы / грёзы          (tears / dreams) - Hackneyed
❌ весна / судьбина       (spring / destiny) - Banal
```
**Why forbidden**: Shows lack of originality

## Part 2: Good Rhyme Characteristics (Memorized)

### ✅ Rich Rhymes (BEST - Aim for 70%+)

**Definition**: Consonant(s) BEFORE stressed vowel match

```
✅ **к**óшка / **к**рóшка     (cat / crumb)
✅ **м**éч / **п**éч           (sword / oven)
✅ **зв**ездá / **гн**ездá     (star / nest)
```

**Why excellent**: Maximum phonetic similarity, shows craft

### ✅ Deep Rhymes (EXCELLENT)

**Definition**: Entire syllable before stress matches

```
✅ **ми**шéние / **ми**лéние   (target / mercy)
✅ **по**казáл / **ло**сказáл   (showed / horse-said)
```

**Why excellent**: Very rare, sophisticated

### ✅ Exact Rhymes (STANDARD - Acceptable)

**Definition**: Match from stressed vowel onward

```
✅ лунá / однá                  (moon / one)
✅ морóз / вопрóс               (frost / question)
```

**Why acceptable**: Clean sound, professional standard

### ✅ Mixed Parts of Speech (PREFERRED)

**Definition**: Rhyme different grammatical categories

```
✅ Noun + Adjective: звездá (star) / чуднá (wonderful)
✅ Noun + Verb (not infinitive): судьбá (fate) / борьбá (struggle/to struggle)
✅ Unexpected: Москвá (Moscow) / молвá (rumor)
```

**Why preferred**: Avoids forbidden patterns, shows originality

- Stress marks indicated with accents

✅ **Filter by Quality**
- "Точные рифмы" (Exact rhymes) - Match from stressed vowel
- "Богатые рифмы" (Rich rhymes) - Consonants before stress match
- "Приблизительные" (Approximate) - Avoid when possible

✅ **Filter by Part of Speech**
- Nouns (существительные)
- Adjectives (прилагательные)
- Verbs (глаголы) - ⚠️ USE WITH CAUTION, avoid infinitives!
- Adverbs (наречия)

✅ **Stress Pattern Search**
- Masculine rhymes: Final syllable stressed (-á, -ó, -éy)
- Feminine rhymes: Penultimate syllable stressed (-ája, -éni-ye)
- Results sorted by stress pattern

## Part 6: Forbidden Rhyme Recognition Exercise - Results

### Analysis of Rhyme Pairs:

1. **любить / говорить** → ❌ FORBIDDEN
   - **Why**: Verb infinitives (both -ить endings)
   - **Rule violated**: Never rhyme verb infinitives

2. **весна / луна** (spring / moon) → ✅ ACCEPTABLE
   - **Why**: Both nouns, different roots, exact rhyme (-на)
   - **Quality**: ⭐⭐⭐ Standard exact rhyme
   - **Notes**: Good, clean rhyme

3. **говорит / звонит** → ❌ FORBIDDEN
   - **Why**: Verb conjugations (both 3rd person singular present)
   - **Rule violated**: Never rhyme same verb form

4. **красивый / счастливый** (beautiful / happy) → ⚠️ QUESTIONABLE
   - **Why**: Both adjectives with -ивый ending (grammatical rhyme)
   - **Rule**: Grammatical endings are forbidden
   - **Assessment**: Technically forbidden, shows lack of craft

5. **зима / судьбина** (winter / destiny) → ⚠️ WEAK/TRITE
   - **Why**: Not forbidden technically, but very trite pair
   - **Quality**: ⭐ Cliché, overused in Russian poetry
   - **Assessment**: Legal but avoid (shows lack of originality)

6. **дома / города** (houses / cities - both genitive) → ❌ FORBIDDEN
   - **Why**: Same grammatical case ending (genitive singular)
   - **Rule violated**: No grammatical case rhymes

7. **любовь / кровь** (love / blood) → ❌ FORBIDDEN
   - **Why**: THE most trite rhyme pair in Russian poetry
   - **Rule violated**: Trite pairs forbidden
   - **Notes**: Instantly marks amateur verse

8. **мороз / вопрос** (frost / question) → ✅ ACCEPTABLE
   - **Why**: Both nouns, different roots, rich rhyme
   - **Quality**: ⭐⭐⭐⭐ Rich rhyme (consonants match)
   - **Notes**: Excellent choice

9. **сказал / показал** (said / showed) → ❌ FORBIDDEN
   - **Why**: Both masculine past tense verbs with -ал
   - **Rule violated**: Never rhyme verb past tense forms

10. **день / тень** (day / shadow) → ✅ ACCEPTABLE
    - **Why**: Both nouns, exact rhyme, not trite
    - **Quality**: ⭐⭐⭐ Standard exact rhyme
    - **Notes**: Clean, acceptable

## Lessons Learned

### Key Insights:

1. **Rich rhymes are achievable**
   - 70% of found rhymes were rich or exact
   - Consonant matching before stress is key
   - Worth extra search time for rich rhymes

2. **Forbidden rhymes are everywhere**
   - Must actively filter out verb rhymes
   - Grammatical endings tempting but forbidden
   - Always check part of speech before accepting

3. **Trite pairs are traps**
   - любовь/кровь is everywhere but forbidden
   - Must force yourself past first result
   - Fresh rhymes show craft and originality

4. **Some words are very difficult**
   - Short words (ночь, день) have few rhymes
   - May require line restructuring
   - Better to change line than use weak rhyme

5. **Speed comes with practice**
   - First searches: 60-90 seconds
   - After practice: 35-55 seconds
   - Target achieved: < 60 seconds average

### Common Mistakes Encountered:

❌ **Accepting first Rifmovnik result** → Often verb or trite pair
✅ **Solution**: Browse through at least 10-15 options

❌ **Missing grammatical rhymes** → -ый adjectives, case endings
✅ **Solution**: Always check part of speech and grammatical form

❌ **Settling for approximate rhymes too quickly**
✅ **Solution**: Search longer for exact or rich rhymes

### Pro Tips Discovered:

💡 **Use genitive/instrumental cases for variety**
- Example: сердце (heart nom.) → сердца (heart gen.) opens new rhymes

💡 **Semantic contrast makes rhymes memorable**
- Example: меч/речь (sword/speech), дуэль/цель (duel/goal)

💡 **Character names need special attention**
- Юлия/Италия is perfect thematically
- Роман/обман (deception) is dramatically fitting

💡 **Keep personal rhyme bank**
- Saves time during actual composition
- Quality control done in advance
