## PHASE 1: PRE-COMPOSITION (10-15 minutes)

### Context Gathering
- [ ] 1.1. Read stanza plan from Chapter outline (what happens in this stanza?)
- [ ] 1.2. Check previous stanza's final lines (continuity)
- [ ] 1.3. Check next stanza's opening (foreshadowing if needed)
- [ ] 1.4. Identify stanza function:
  - ☐ Narrative (advancing plot)
  - ☐ Digressive (commentary, philosophy)
  - ☐ Lyrical (emotion, beauty)
  - ☐ Transitional (scene/time change)
  - ☐ Dialogue (character speech)

### Voice Selection
- [ ] 1.5. Whose voice?
  - ☐ Narrator (go to 1.6)
  - ☐ Character (go to 1.8)

- [ ] 1.6. **IF NARRATOR**: Which tone(s) for this content?
  - ☐ Ironic (____%)
  - ☐ Sympathetic (____%)
  - ☐ Philosophical (____%)
  - ☐ Playful (____%)

- [ ] 1.7. **IF NARRATOR**: Check chapter tone distribution table (voice notes)

- [ ] 1.8. **IF CHARACTER**: Review character voice profile
  - ☐ Roman: Poetic, elevated, passionate
  - ☐ Yulia: Direct, decisive, practical→romantic
  - ☐ Merkury: Witty, bawdy, irreverent
  - ☐ Matryona: Colloquial, rambling, domestic
  - ☐ Lavrentiy: Philosophical, measured, balanced

### Content Planning
- [ ] 1.9. List 3-5 key concepts this stanza must convey
- [ ] 1.10. Identify any required Russian words (names, places, specific terms)
- [ ] 1.11. Note any imagery/metaphors to include

**✓ CHECKPOINT**: Clear on voice, tone, content before proceeding

## PHASE 3: LINE-BY-LINE DRAFTING (30-40 minutes)

### For EACH Line (repeat 14 times):

**Draft Line**:
- [ ] 3.1. Write Russian text ending with planned rhyme word
- [ ] 3.2. Content: Does line express what it should?
- [ ] 3.3. Voice: Does it match selected voice/tone?

**Verify Stress**:
- [ ] 3.4. Look up stress for EVERY word (Wiktionary)
- [ ] 3.5. Mark stress on draft: á é í ó ú ы́ э́ ю́ я́
- [ ] 3.6. Never guess - always verify!

**Count Syllables**:
- [ ] 3.7. Count: Line has ____ syllables
- [ ] 3.8. Check: ☐ 8 (masculine) or ☐ 9 (feminine) ✓

**Verify Meter** (Iambic Tetrameter):
- [ ] 3.9. Mark pattern: u — u — u — u — (u)
- [ ] 3.10. Syllable 2 stressed? ☐ YES (preferred) ☐ NO (pyrrhic OK)
- [ ] 3.11. Syllable 4 stressed? ☐ YES (preferred) ☐ NO (pyrrhic OK)
- [ ] 3.12. Syllable 6 stressed? ☐ YES (preferred) ☐ NO (pyrrhic OK)
- [ ] 3.13. Syllable 8 stressed? ☐ YES ✓ **MANDATORY**
- [ ] 3.14. **CRITICAL**: NO odd syllables stressed (1,3,5,7)? ☐ CONFIRMED
- [ ] 3.15. If line 8: Final stress syllable 8? ☐ YES ✓ **INVIOLABLE**

**Natural Sound**:
- [ ] 3.16. Read line aloud
- [ ] 3.17. Sounds natural in Russian? ☐ YES ☐ NO (revise)
- [ ] 3.18. Word order natural (not forced for meter)? ☐ YES

**If line doesn't work**:
- [ ] 3.19. Try different word order
- [ ] 3.20. Replace problematic word(s)
- [ ] 3.21. If still broken, consider changing rhyme word
- [ ] 3.22. Recheck stress verification

**✓ CHECKPOINT AFTER EACH LINE**: Line is technically correct before proceeding to next

## 🚨 TROUBLESHOOTING GUIDE

### Problem: Can't find good rhyme
**Solution**:
- Try different grammatical form of line-end word
- Restructure line completely
- Use Rifmovnik.ru "rich rhymes only" filter
- Consider changing earlier rhyme pair to open options

### Problem: Line doesn't scan
**Solution**:
- Verify EVERY word's stress with dictionary
- Check for odd-position stresses (forbidden!)
- Try different word order
- Replace problematic word with synonym

### Problem: Sounds forced/unnatural
**Solution**:
- Read Pushkin's Onegin for examples
- Try shorter sentences
- Use enjambment (carry thought across lines)
- Revise 3-5 times - naturalness comes with iteration

### Problem: Lost voice consistency
**Solution**:
- Stop, read voice profile again
- Read last 3 stanzas aloud
- Identify where voice drifted
- Revise back to consistent voice

### Problem: Taking too long
**Solution**:
- Don't rush - quality over speed
- Early stanzas slower (60-90 min normal)
- Speed increases with practice (target: 30-45 min)
- Take breaks between stanzas
