## 🚀 Workflow Recommendations

### Phase 1: Pre-Writing (Before Each Session)
1. Review relevant section from Russian Prosody Guide
2. Check Pushkin Poetry Style for voice reminders
3. Review previous stanzas for consistency
4. Open Rifmovnik.ru for rhyme searching

### Phase 2: During Writing
1. Keep Russian Prosody Guide open (Section 6 - Onegin Stanza)
2. Reference Character/Dialogue Guide for character voices
3. Check Narrator Creation Guide for narrator voice
4. Use rhyme dictionaries as needed

### Phase 3: Revision
1. Check meter against Russian Prosody Guide (Section 5)
2. Verify rhyme quality against Rhyme and Meter Guide (Section 5)
3. Check character voice consistency
4. Verify cultural appropriateness

### Phase 4: Chapter Completion
1. Compare structure to Eugene Onegin Analysis
2. Check pacing and balance
3. Verify narrator voice development
4. Review all cross-references

## 📝 Notes for Claude Code

**When composing poetry:**
1. Always verify Russian stress patterns - don't guess
2. Always check rhyme quality - avoid verb rhymes and grammatical rhymes
3. Always maintain narrator voice consistency
4. Always respect the Onegin stanza form (aBaBccDDeFFeGG)
5. Always study examples from Eugene Onegin before innovating

**Quality checklist:**
- [ ] Meter correct (iambic tetrameter)
- [ ] Rhyme scheme correct (aBaBccDDeFFeGG)
- [ ] Stress patterns verified
- [ ] Rhyme quality high (rich rhymes preferred)
- [ ] No verb rhymes or grammatical rhymes
- [ ] Character voice consistent
- [ ] Narrator voice consistent
- [ ] Cultural elements appropriate
- [ ] Natural-sounding dialogue
- [ ] Balanced narrative and lyrical elements
