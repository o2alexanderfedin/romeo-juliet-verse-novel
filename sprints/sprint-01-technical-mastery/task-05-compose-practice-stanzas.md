## Steps for Each Practice Stanza

### Phase 1: Planning (10-15 minutes)

1. **Choose Topic**: Pick from list above
2. **Define Goal**: What do you want to say in this stanza?
3. **Identify Tone**: Descriptive? Philosophical? Ironic?
4. **List Key Words**: What Russian words will you definitely use?
5. **Verify Stress**: Look up stress for all key words NOW
6. **Find Rhymes**: For key words, find rhyme options using Rifmovnik.ru
7. **Rough Structure**: Sketch what each line will express

### Phase 2: Drafting (30-60 minutes)

Follow this process for each line:

**Lines 1 & 3 (feminine, rhyme 'a')**:
1. Draft line 1 in Russian
2. Count syllables (should be 9)
3. Mark stress patterns
4. Verify final stress on syllable 8
5. Draft line 3 to rhyme with line 1
6. Verify rhyme quality (not verb, not grammatical)
7. Check both lines scan correctly

**Lines 2 & 4 (masculine, rhyme 'B')**:
1. Draft line 2 (8 syllables, stress on syllable 8)
2. Verify meter
3. Draft line 4 to rhyme
4. Verify rhyme quality
5. Check scansion

### Phase 3: Verification (15-20 minutes)

Use **INDEX_TECHNICAL_QUICK_REFERENCE.md** verification checklist (lines 260-293):

**Meter Check**:
- [ ] 8 syllables per line (9 for feminine)
- [ ] Final stress on syllable 8 (MANDATORY)
- [ ] No odd positions stressed (1, 3, 5, 7)
- [ ] At least 2-3 stresses per line
- [ ] Pyrrhic variations natural, not forced

**Rhyme Check**:
- [ ] Follows aBaBccDDeFFeGG pattern
- [ ] Feminine rhymes on lowercase (a, c, e)
- [ ] Masculine rhymes on uppercase (B, D, F, G)
- [ ] NO verb infinitive or conjugation rhymes
- [ ] NO grammatical ending rhymes
- [ ] NO overused trite pairs
- [ ] Prefer rich rhymes
- [ ] Mix parts of speech

**Content Check**:
- [ ] Expresses coherent thought
- [ ] Natural language flow
- [ ] Connects within itself logically

### Phase 4: Revision (20-30 minutes)

1. **Read Aloud**: Does it sound natural?
2. **Identify Problems**: Which lines feel forced?
3. **Fix Weak Rhymes**: Replace poor quality rhymes
4. **Fix Meter Issues**: Adjust words for better scansion
5. **Polish Language**: Stronger verbs, clearer images
6. **Read Aloud Again**: Improvement?

### Phase 5: Documentation (10 minutes)

For each practice stanza, document:
- Russian text (Cyrillic)
- Transliteration with stress marks
- English translation (optional)
- Scansion notation
- Rhyme scheme verification
- Self-assessment notes
- Problems encountered
- Lessons learned

## Common Problems and Solutions

### Problem 1: Can't Find Good Rhyme
**Solution**:
- Try different grammatical form of line-end word
- Restructure entire line to end with different word
- Use Rifmovnik.ru filters (rich rhymes only)
- Don't settle for verb rhyme - keep searching

### Problem 2: Line Doesn't Scan
**Solution**:
- Verify EVERY word's stress
- Check if odd positions have stressed syllables (forbidden)
- Try different word order (Russian allows flexibility)
- Replace problematic word with synonym

### Problem 3: Language Feels Forced
**Solution**:
- Read Pushkin's Eugene Onegin for natural flow examples
- Try shorter sentences
- Use enjambment (carry thought across lines)
- Revise multiple times - naturalness comes with revision

### Problem 4: Running Out of Time
**Solution**:
- Don't rush - quality over speed
- One good stanza better than five bad ones
- Take breaks between stanzas
- This is practice - no deadline

### Problem 5: Perfectionism Paralysis
**Solution**:
- Draft quickly first (imperfect is OK)
- Revise later
- Remember: this is practice, not the novel
- Learn from mistakes - that's the point
