## Steps

### 1. Browser Setup
1. Open browser with multiple tabs
2. Tab 1: **Rifmovnik.ru** (https://rifmovnik.ru/) - Primary rhyme dictionary
3. Tab 2: **Wiktionary Russian** (https://ru.wiktionary.org/) - Stress verification
4. Tab 3: **RussianGram.com** - Grammar and stress patterns
5. Tab 4: Local `INDEX_TECHNICAL_QUICK_REFERENCE.md` for fast reference
6. Bookmark these pages for quick access

### 2. File System Organization
1. Create composition workspace:
   ```bash
   mkdir -p composition/chapter_01/drafts
   mkdir -p composition/chapter_01/final
   mkdir -p composition/practice_stanzas
   ```
2. Verify all planning documents accessible:
   - `planning/structure/chapter_01_stanza_plan.md`
   - `planning/narrator/narrator_persona.md`
   - `planning/characters/character_name_mapping.md`

### 3. Reference Documents Open
1. Open in editor/viewer:
   - `INDEX_TECHNICAL_QUICK_REFERENCE.md` (keep visible)
   - `planning/narrator/narrator_persona.md` (for voice reference)
   - `planning/structure/chapter_01_stanza_plan.md` (for current work)

### 4. Stress Verification Tool Test
1. Go to Wiktionary Russian
2. Test looking up: Москва, любовь, судьба
3. Verify you can identify stress marks (accent marks)
4. Practice: Look up 10 random Russian words and mark stress

### 5. Rhyme Dictionary Test
1. Go to Rifmovnik.ru
2. Test search for: зима (winter)
3. Verify results show rhyming words
4. Practice filtering by rhyme quality
5. Test 5 different words to familiarize with interface

### 6. Create Composition Template
1. Create file: `composition/stanza_template.md`
2. Include sections for:
   - Russian text (Cyrillic)
   - Transliteration with stress
   - English translation (optional)
   - Scansion notes
   - Rhyme scheme verification
   - Quality checklist

## Verification Steps

### Test Workflow:
1. Pick a Russian word: **вражда** (feud)
2. Look up stress: вражда́ (vrazh-DÁ) - stress on final syllable
3. Find rhymes on Rifmovnik.ru: гряда, звезда, езда, беда...
4. Check rhyme quality: -дá endings (masculine rhyme)
5. Time yourself: should complete in <90 seconds total

If you can complete this test smoothly, environment is ready.
