## Steps

### 1. Review Technical Specifications (15 minutes)
1. Read INDEX_TECHNICAL_QUICK_REFERENCE.md lines 7-40 (Onegin Stanza Quick Specs)
2. Memorize rhyme scheme: **aBaBccDDeFFeGG**
3. Understand feminine vs. masculine rhyme positions
4. Review iambic tetrameter pattern

### 2. Source Onegin Stanzas (15 minutes)
1. Options for finding Russian text:
   - FEB-web (Fundamental Electronic Library - Russian)
   - Project Gutenberg (if available)
   - Eugene Onegin Deep Analysis document (contains examples)
2. Select 10-15 stanzas from different chapters:
   - 3-4 from Chapter 1 (narrative introduction)
   - 2-3 from Chapter 2 (character description)
   - 2-3 from Chapter 4 (emotional/lyrical)
   - 2-3 from Chapter 7 (dramatic action)
   - 2-3 from Chapter 8 (philosophical)

### 3. Deep Analysis of Each Stanza (10-15 minutes per stanza)

For each stanza, analyze:

#### A. Rhyme Scheme Verification
- Mark each line: a, B, a, B, c, c, D, D, e, F, F, e, G, G
- Verify feminine rhymes (lowercase): lines 1, 3, 5, 6, 9, 12
- Verify masculine rhymes (uppercase): lines 2, 4, 7, 8, 10, 11, 13, 14
- Check rhyme quality (exact, rich, or approximate)

#### B. Metrical Analysis
- Count syllables per line (should be 8 for masculine, 9 for feminine)
- Mark stress patterns (u = unstressed, — = stressed)
- Identify pyrrhic feet (unstressed substitutions)
- Verify final stress on syllable 8 (mandatory!)

#### C. Content Function
- Is stanza narrative, digressive, lyrical, or transitional?
- What is narrator's tone? (ironic, sympathetic, philosophical)
- How does stanza connect to adjacent stanzas?

#### D. Technical Features
- Enjambment (lines flowing into next) or end-stopped?
- Caesura (pause) placement within lines?
- Vocabulary level (high/middle/low register)?
- Any metafictional moments?

### 4. Create Analysis Document (30 minutes)
1. Create file: `composition/practice_stanzas/onegin_analysis.md`
2. For each stanza, document:
   - Russian text
   - Rhyme scheme marked
   - Scansion (metrical pattern)
   - Content notes
   - Technical observations
   - What makes it effective?

### 5. Identify Patterns (30 minutes)
Across all analyzed stanzas, note:
- Common enjambment patterns
- How Pushkin handles transitions
- How digressions begin and end
- Variety in sentence structure within stanzas
- Balance of narrative vs. commentary

### 6. Memorization Exercise (20 minutes)
1. Choose 2-3 favorite stanzas
2. Read aloud multiple times
3. Try to internalize rhythm and flow
4. Pay attention to how Russian sounds within meter
