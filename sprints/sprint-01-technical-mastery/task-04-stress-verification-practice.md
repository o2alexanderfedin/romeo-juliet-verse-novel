## Critical Rule to Internalize

**⚠️ NEVER GUESS RUSSIAN STRESS** ⚠️

Russian stress patterns are:
- Unpredictable (cannot be derived from spelling)
- Mobile (change in different grammatical forms)
- Critical for meter (wrong stress = broken verse)
- Must be verified for EVERY word

**Reference**: INDEX_TECHNICAL_QUICK_REFERENCE.md lines 113-115

## Steps

### 1. Understand Stress Indicators (10 minutes)

**Most Reliable Indicator**:
- **ё** (yo) is ALWAYS stressed
- Example: всё (VSYO), ёлка (YÓL-ka), берёза (be-RYÓ-za)

**Monosyllables**:
- One syllable = automatically stressed (or unstressed function words)
- Example: дом (DOM), но (NO - unstressed particle)

**Stress Marks in Dictionaries**:
- Acute accent over vowel: á, é, í, ó, ú, ы́, э́, ю́, я́
- Some dictionaries use other marks
- Wiktionary uses IPA: /maskˈva/ → stress on "va"

**Reference**: INDEX_TECHNICAL_QUICK_REFERENCE.md lines 117-125

## Verification Steps

### Self-Test 1: ё Recognition
✓ ё is always stressed
- Can you identify ё in: всё, берёза, Матрёна?

### Self-Test 2: Monosyllable Rule
- Which are stressed: дом, кот, мать, он, в, на?
- Answer: дом, кот, мать (content words) are stressed; он, в, на (function words) typically unstressed in meter

### Self-Test 3: Dictionary Navigation
- Pick random Russian word
- Find stress in < 30 seconds using Wiktionary

## Critical Reminders

### 🔴 NEVER GUESS STRESS
Even if word "looks like" it should be stressed a certain way.
Even if you "think you know" the stress.
Even if it "sounds right" to you.
**ALWAYS VERIFY**.

### Why This Matters:
- Wrong stress = wrong syllable count
- Wrong syllable count = broken meter
- Broken meter = unpublishable verse
- One wrong stress can ruin an entire stanza

### Workflow Integration:
During composition, when you write ANY Russian word:
1. Write the word
2. IMMEDIATELY verify stress
3. Mark stress in your draft
4. Only then count syllables for meter

This becomes automatic with practice.

---

## Pro Tips

1. **Mark Stress Immediately**: Don't draft whole stanza then verify. Mark as you write.
2. **Create Reference Sheet**: Common words you'll use often (Moscow, love, fate, etc.)
3. **Learn ё Words**: ё is gift - always stressed, no lookup needed
4. **Use Multiple Sources**: If uncertain, cross-reference Wiktionary with other dictionaries
5. **Check Each Form**: Don't assume plural has same stress as singular
6. **Build Stress Intuition**: After 100+ lookups, patterns emerge (but still verify!)
