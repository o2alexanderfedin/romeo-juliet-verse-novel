## Workflow Components to Include

### 1. Pre-Composition Phase
- [ ] Review stanza plan for this stanza (from Chapter plan)
- [ ] Determine function (narrative/digressive/transitional)
- [ ] Identify whose voice (narrator/character)
- [ ] If narrator: choose appropriate tone
- [ ] List key concepts to convey
- [ ] Check adjacent stanzas for continuity

### 2. Rhyme Planning Phase
- [ ] Identify potential rhyme words for this stanza
- [ ] Verify rhyme words are NOT verbs
- [ ] Look up stress for all rhyme candidates
- [ ] Find rhyme pairs using Rifmovnik.ru
- [ ] Assess rhyme quality (rich > exact > approximate)
- [ ] Reserve 7 rhyme pairs (14 lines need rhymes)

### 3. Line-by-Line Drafting Phase

**For Each Line**:
- [ ] Draft line in Russian
- [ ] Verify stress for EVERY word (Wiktionary)
- [ ] Count syllables (8 for masculine, 9 for feminine)
- [ ] Mark stress pattern (u — u — u — u —)
- [ ] Verify syllable 8 is stressed (MANDATORY)
- [ ] Check no odd positions stressed (1, 3, 5, 7)
- [ ] Read aloud - does it sound natural?

**For Each Rhyme Pair**:
- [ ] Verify rhyme scheme matches plan (aBaBccDDeFFeGG)
- [ ] Verify rhyme quality (not weak)
- [ ] Verify NOT forbidden (no verbs, no grammatical)
- [ ] Verify feminine/masculine matches scheme

### 4. Voice Verification Phase
- [ ] Read entire stanza aloud
- [ ] Voice consistent throughout?
- [ ] If narrator: tone appropriate?
- [ ] If character: voice distinctive?
- [ ] Register matches content?
- [ ] Reader address (if any) natural?

### 5. Technical Verification Phase

**Use INDEX_TECHNICAL_QUICK_REFERENCE.md checklist**:

**Meter**:
- [ ] Each line 8 syllables (or 9 for feminine)
- [ ] Final stress syllable 8 on EVERY line
- [ ] No odd positions stressed
- [ ] At least 2-3 stresses per line
- [ ] Pyrrhic variations natural

**Rhyme**:
- [ ] Scheme: aBaBccDDeFFeGG correct
- [ ] Feminine on lowercase (a, c, e)
- [ ] Masculine on uppercase (B, D, F, G)
- [ ] NO verb rhymes
- [ ] NO grammatical rhymes
- [ ] NO trite pairs
- [ ] Rich rhymes preferred
- [ ] Mixed parts of speech

**Content**:
- [ ] Serves narrative or lyrical purpose
- [ ] Appropriate pacing
- [ ] Connects to adjacent stanzas
- [ ] Cultural elements appropriate

### 6. Revision Phase
- [ ] Identify weakest line(s)
- [ ] Identify weakest rhyme(s)
- [ ] Any forced-sounding language?
- [ ] Any metrical issues?
- [ ] Revise problem areas
- [ ] Re-verify after changes
- [ ] Read aloud again
- [ ] Acceptable quality?

### 7. Documentation Phase
- [ ] Mark transliteration with stress
- [ ] Note scansion (optional but helpful)
- [ ] Save stanza to appropriate file
- [ ] Update progress tracking
- [ ] Note any lessons learned

## Personalization Instructions

### Step 1: Review Your Practice Results

From tasks 05-06:
- What mistakes did you make most often?
- What took longest?
- What felt most difficult?
- What came naturally?

### Step 2: Emphasize Your Weak Areas

**If you struggled with rhyme finding**:
- Add extra checkpoints in Rhyme Planning Phase
- Build rhyme bank before drafting
- Check rhyme quality twice

**If you had stress errors**:
- Verify stress IMMEDIATELY as you write each word
- Double-check with second source
- Mark stress before moving to next word

**If meter was problematic**:
- Count syllables twice
- Mark scansion for every line
- Read aloud more frequently

**If voice was inconsistent**:
- Check voice before AND after each stanza
- Compare to voice profiles more often
- Read aloud in character/narrator voice

### Step 3: Streamline Your Strengths

**If rhyme finding is easy for you**:
- Reduce time spent on rhyme planning
- Trust your instinct more

**If stress verification is fast**:
- Batch verify (multiple words at once)
- Build personal stress reference

**If voice comes naturally**:
- Less frequent voice checks needed
- Trust your ear

### Step 4: Create Your Workflow Document

**Include**:
1. Pre-composition checklist
2. Drafting process (step-by-step)
3. Verification checklist (comprehensive)
4. Revision guidelines
5. Common mistakes to watch for (YOUR mistakes)
6. Personal reminders
7. Estimated time per stanza (your average)

## Workflow Optimization Tips

### Start Comprehensive, Then Streamline
- First 50 stanzas: Use full checklist every time
- After 50: Start internalizing, use selectively
- After 100: Many steps automatic, checklist for verification only

### Batch Similar Steps
- Don't switch between drafting and verification constantly
- Draft several lines, THEN verify all at once
- Or: Draft → Verify → Draft → Verify (find your rhythm)

### Use Templates
- Create stanza template file
- Copy-paste for each new stanza
- Reduces setup time

### Leverage Technology
- Keep frequently-used links bookmarked
- Use text expanders for common phrases
- Consider dual monitors (editor + references)

## Example Workflow Variations

### Variation A: Rhyme-First Approach
1. Find all 7 rhyme pairs first
2. Build lines around fixed rhyme words
3. Adjust as needed

**Good for**: People who struggle with rhyme finding

### Variation B: Content-First Approach
1. Draft all 14 lines without worrying about rhyme
2. Then adjust lines to create rhymes
3. Revise heavily

**Good for**: People who need natural language flow first

### Variation C: Sequential Pairs Approach
1. Draft lines 1 & 3, verify, move on
2. Draft lines 2 & 4, verify, move on
3. Continue pair by pair

**Good for**: People who like completing small units

**Choose what works for YOU** (or hybrid approach).
