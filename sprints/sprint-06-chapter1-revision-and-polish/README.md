## Task Breakdown (8 tasks)

### Task 01: Complete Technical Audit (All 55 Stanzas)
Verify every stanza: form, meter, rhyme, stress.

### Task 02: Voice Consistency Audit
Check narrator voice consistency across chapter.

### Task 03: Character Voice Audit
Verify Roman, Merkury, Benedikt, Yulia, Matryona voices consistent.

### Task 04: Strengthen Weak Rhymes
Identify and replace all weak/approximate rhymes with rich/exact.

### Task 05: Polish Forced Language
Find and revise any unnatural-sounding lines.

### Task 06: Optimize Narrative Flow
Check transitions, pacing, balance.

### Task 07: Read-Aloud Test
Read entire chapter aloud, mark issues, fix.

### Task 08: Final Quality Assessment
Make go/no-go decision for Chapter 2.
